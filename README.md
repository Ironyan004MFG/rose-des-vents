# Grande Guilde de la Rose des Vents

Babillard de quêtes interactif pour une campagne D&D 5.5e de style West Marches sur la Sword Coast.

Site : https://ironyan004mfg.github.io/rose-des-vents/

## Mettre à jour les quêtes
1. Ouvrir le site, cliquer sur « Mode DM » et entrer le mot de passe.
2. Ajouter ou modifier les quêtes, puis cliquer sur « Télécharger le site mis à jour ».
3. Remplacer `index.html` dans ce dépôt par le fichier téléchargé.
